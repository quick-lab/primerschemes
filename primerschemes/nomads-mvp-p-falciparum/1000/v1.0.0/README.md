## Description

The NOMADS Minimum Viable Panel (MVP) approach enables rapid genomic surveillance of P. falciparum malaria using targeted nanopore sequencing. It includes amplicons targeting key antimalarial drug resistance genes (pfcrt, pfdhfr, pfdhps, pfkelch13, pfmdr1), rapid diagnostic test (RDT) antigens (pfhrp2, pfhrp3), a high diversity gene (pfama1), and the RTS'S vaccine target (pfcsp).
